# Yuhum Studios Website

A full-stack booking website for Yuhum Studios built with React, Node.js, Express, and PostgreSQL.

## Features

- Online booking
- Calendar scheduling
- Email confirmation
- Admin dashboard
- Customer management

## Technologies

- React
- Tailwind CSS
- Express.js
- PostgreSQL
- EmailJS

## Installation

```bash
git clone https://github.com/username/project.git

cd project

npm install

npm run dev
```

## Environment Variables

Create a .env file.

```
DATABASE_URL=
JWT_SECRET=
EMAIL_SERVICE_ID=
EMAIL_TEMPLATE_ID=
```
